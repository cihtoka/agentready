# AI 쇼핑 에이전트 친화 웹 설계 가이드라인

AI 쇼핑 에이전트는 화면을 눈으로 보지 않고 HTML 구조, 구조화 데이터, 표준 태그를 읽어 검색·비교·장바구니 담기를 수행한다. 아래 항목은 에이전트가 사이트를 정확히 이해하고 끝까지 조작할 수 있게 하는 최소 설계 원칙이다.

## jsonld: 상품 구조화 데이터(JSON-LD)
상품 상세 페이지에는 schema.org Product 타입의 JSON-LD를 넣어 상품명, 이미지, 가격(offers.price), 통화(priceCurrency), 재고(availability)를 기계가 바로 읽게 한다. 본문 디자인을 해석하지 않아도 핵심 정보를 정확히 얻을 수 있어 에이전트의 오인식과 환각이 크게 줄어든다.

## price: 가격 마크업
가격은 숫자만 두지 말고 통화 단위를 함께 표기하고 itemprop="price" 와 content 속성에 숫자 값을 넣는다. 이미지로 된 가격이나 단위가 없는 숫자는 에이전트가 할인가, 정가, 배송비를 구분하지 못해 비교 구매에서 제외되기 쉽다.

## availability: 재고 상태 표기
재고와 구매 가능 여부는 schema.org availability 값(InStock, OutOfStock)으로 구조화한다. 품절 상품을 추천하거나 재고를 확인하지 못해 구매를 포기하는 상황을 막는다. 재고 값은 반드시 실제 재고 시스템 기준으로 채워야 한다.

## clickables: 표준 클릭 요소(a/button)
이동은 a 태그의 href, 동작은 button 태그를 사용한다. div, span, td 에 onclick 만 붙인 요소는 에이전트가 클릭 가능한지 판단할 수 없어 탐색이 중간에 끊긴다. 검색창과 담기 버튼은 form 으로 감싸 제출 경로를 명확히 한다.

## labels: 폼 입력 라벨
모든 입력 요소는 label 태그나 aria-label 로 용도를 밝힌다. placeholder 는 입력 시 사라지고 접근성 트리에서 신뢰도가 낮다. 수량, 옵션, 검색어 입력의 의미를 알아야 에이전트가 올바른 값을 채울 수 있다.

## landmarks: 시맨틱 랜드마크
header, nav, main, footer 태그로 페이지 영역을 구분한다. 에이전트는 main 영역에서 본문 정보를 우선 추출하고 nav 에서 이동 경로를 찾는다. 레이아웃을 div 로만 구성하면 광고, 메뉴, 본문이 뒤섞여 잘못된 정보를 읽는다.

## headings: 제목 구조(h1~h6)
페이지당 h1 은 하나만 두고 h2, h3 순서를 건너뛰지 않는다. 제목 계층은 에이전트가 페이지의 주제와 섹션 구조를 요약하는 기준이 된다. 상품명은 h1 에 넣는 것이 가장 안전하다.

## meta: title/description/OG 메타
의미 있는 title, 20자 이상의 meta description, Open Graph 태그를 제공한다. 검색 결과나 에이전트의 사전 탐색 단계에서 페이지를 열어 보지 않고도 내용을 판단하는 근거로 쓰인다. 제목이 untitled 같은 기본값이면 신뢰도가 낮은 페이지로 분류된다.

## alt: 이미지 대체 텍스트
모든 상품 이미지에 상품을 설명하는 alt 텍스트를 넣는다. 에이전트는 이미지를 직접 해석하지 못하는 경우가 많아 alt 가 이미지의 유일한 정보가 된다. 장식용 이미지가 아니라면 빈 alt 는 피한다.

## machine_files: robots.txt / llms.txt
robots.txt 로 에이전트의 접근 정책을 명확히 하고, llms.txt 에 사이트 개요와 주요 페이지 목록을 마크다운으로 제공한다. 에이전트가 사이트 구조를 한 번에 파악해 불필요한 탐색을 줄인다. 접근 허용 범위는 운영 정책에 맞게 정해야 한다.
